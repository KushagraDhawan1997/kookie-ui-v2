Setting up takes three steps: adding the package, importing one stylesheet, and wrapping your
app in a `Theme`. There's no config file or build plugin because every value is calculated
beforehand and shipped as CSS custom properties.

## Add the package

`@kookie-ui/react` is pre-release and isn't on npm yet, so for now you build it from the
repository:

```bash
git clone https://github.com/KushagraDhawan1997/kookie-ui-v2
cd kookie-ui-v2
pnpm install
pnpm run build
```

Then depend on it from an app in the same workspace:

```json title="package.json"
{
  "dependencies": {
    "@kookie-ui/react": "workspace:*"
  }
}
```

Once the package is on npm, you'll install it with `pnpm add @kookie-ui/react` instead.
The rest of the setup is the same. You need React 19 and React DOM 19.

## Import the stylesheet once

```tsx
import "@kookie-ui/react/styles.css";
```

Import it at the root of your app. This single file contains everything: the colour and
spacing values, the shared rules for controls, and the rules for every component.

## Wrap your app in a Theme

```tsx
import "@kookie-ui/react/styles.css";
import { Theme } from "@kookie-ui/react";

export default function App({ children }: { children: React.ReactNode }) {
  return <Theme>{children}</Theme>;
}
```

`Theme` holds your app's eight settings: appearance, radius, density, depth, material, size,
contrast, and pointer. Everything inside it picks up those settings automatically. The
[Theming](/start/theming) chapter explains what each one does.

## Set the page background

The library doesn't paint your page's background. Set it in your own CSS:

```css
body {
  margin: 0;
  min-height: 100dvh;
  background: var(--color-page);
  color: var(--color-text);
  font-family: var(--font-body);
}
```

If your page is mostly cards, use `--color-ground` instead. It's slightly darker than the page
in light mode and slightly lighter in dark mode, so the cards have something to sit on.

## Set dark mode before the page paints

Your server can't know whether to render light or dark, because a saved preference and the
operating system's setting both live in the browser. If the server guesses, you get one of two
problems: the page flashes the wrong colours, or React complains that the server and browser
disagree.

The fix is a small script in your `<head>` that writes the answer onto `<html>` before
anything paints. Then set your root `Theme` to `appearance="inherit"`, which tells it not to
write an appearance of its own.

```html
<script>
  (function () {
    var e = document.documentElement;
    var read = function (k) {
      try { return localStorage.getItem(k); } catch (err) { return null; }
    };
    var a = read("kui-appearance");
    var dark = a === "light" ? false
      : a === "dark" ? true
      : matchMedia("(prefers-color-scheme: dark)").matches;
    e.setAttribute("data-appearance", dark ? "dark" : "light");
    var c = read("kui-contrast");
    if (c === "high" || c === "normal") e.setAttribute("data-contrast", c);
  })();
</script>
```

```tsx
<html lang="en" suppressHydrationWarning>
  <head>{/* the script above */}</head>
  <body>
    <Theme appearance="inherit">{children}</Theme>
  </body>
</html>
```

Two details in that script matter, and both are easy to get wrong.

**Put the `try` around the read, not around everything.** Some browsers throw an error when
you read `localStorage`. Safari throws when someone blocks all cookies. If you wrap the
whole function in one `try`, that error also skips the two `setAttribute` calls, and someone
with a dark operating system gets a light page. Reading the media query never throws, so guard
the read and leave the writes outside.

**Write both attributes onto the same element.** The high-contrast colours only apply when
`data-appearance` and `data-contrast` sit on one element together. If your script takes over
the appearance, it has to take over the contrast too.

## Point the font tokens at your fonts

The library doesn't ship any font files. It reads three tokens, so point them at whatever
fonts you serve:

```css
:root {
  --font-body: "Inter", system-ui, sans-serif;
  --font-heading: var(--font-body);
  --font-mono: "Berkeley Mono", ui-monospace, monospace;
}
```

If you don't set them, they fall back to the system fonts.

## Check that it worked

```tsx
import { Button, Card, Stack, Text } from "@kookie-ui/react";

export function Smoke() {
  return (
    <Card size="3">
      <Stack gap="3">
        <Text>The card around this text has a corner, a fill, and a border.</Text>
        <Button tone="accent" emphasis="loud">Everything is wired up</Button>
      </Stack>
    </Card>
  );
}
```

If the card has rounded corners and the button shows your accent colour, the stylesheet and
the Theme are both working.
