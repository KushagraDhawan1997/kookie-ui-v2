# Gestures

A gesture is quick for people who know it and invisible to everyone else. Every gesture in Kookie
has a visible equivalent, so nobody has to discover a gesture to finish a task.

## Give every gesture a visible equivalent

- **Swipe a sheet closed:** Escape and a press on the dimmed background close it too.
- **Drag a sidebar's edge:** With `resizable`, the arrow keys resize it as well.
- **Right-click or long-press:** A `ContextMenu` opens at the pointer, so put every action in it
  somewhere else too, such as a button or a `Menu`.
- **Drag a text area's corner:** The box also grows as people type.

## Don't add gestures of your own

A gesture you invent is a command that only some people will find. Add a visible control
instead, and keep your gesture as a shortcut only if a control already does the same thing.
