# What's new in Kookie UI

## October 22

1. **Front-page hero.** The docs front page opens with a real builder on the line grid, edge to edge above the title.

## October 21

1. **ShellNotice.** A notice about the whole app sits in its own row above the Shell's header. The docs site's work-in-progress notice now uses it on every page, and stays dismissed after a reload.

## October 17

1. **Docs ship in the package.** Every docs page is included as Markdown at the version you install, and the agent rules point your coding agent to the page to read before it builds a form, a dialog or an app frame.

## October 16

1. **Reorganized docs.** Principles say why Kookie exists and what it takes from Apple. Start gains a Composition chapter, and Vocabulary is gone. Foundations are renamed Appearance, Interaction, Scale and Shape, and Responsiveness moves to Patterns.

## October 15

1. **Components filed by job.** The component index groups components by what a person is doing (Act, Choose, Enter, Read and more), and each page names the component to use instead.
2. **Material scale 1 to 9.** Glass comes in nine stacked steps, and dark mode glass is quieter.
3. **Flush work area.** The docs work area sits flush, like every other pane.
4. **Work-in-progress notice.** The docs site says it is a work in progress.
5. **K mark.** The K mark is the logo, favicon and Apple touch icon.

## September 25

1. **New package name.** The React package is `@kushagradhawan/kookie-ui-react`.

## September 20

1. **No motion.** Overlays, menus, tabs and controls appear at once. Nothing fades or travels.

## September 19

1. **Grey accent.** The default accent is grey.
2. **Carousel, MessageScroller and Confirmation.** Three new components, plus the Conversation block.
3. **Examples tab.** Every component page has an Examples tab.
4. **Every block in the sidebar.** Blocks are listed in the docs sidebar, like components.
5. **Nested panes.** A pane inside a pane has matching, concentric corners.
6. **Lighter headings.** Headings and page titles use medium weight. Size sets rank.
7. **Bigger display sizes.** Display steps 7 to 9 are 32, 44 and 64.
8. **Plain-English docs.** Every chapter is rewritten in Simplified Technical English.

## September 15

1. **Builder sidebar.** The builder adds components from a sidebar tab and groups the inspector into sections.
2. **New type.** The docs read in Inter, headings use Inter Tight, and the wordmark is PP Acma.

## September 9

1. **Tab bar on phones.** On a phone, the Shell's rail becomes a tab bar.

## September 8

1. **Collapsing toolbar.** A toolbar folds its extra controls into a menu when the row runs out of room.
2. **Theme panel.** The docs have a Theme panel beside the appearance toggle.

## September 5

1. **Resizable sidebar.** The docs sidebar can be resized, and its chrome floats.

## September 1

1. **Live specimens.** Component pages have knobs that drive the example and rewrite its code.
2. **Toggle, Avatar, Badge, Table and Accordion.** Five more components ship.

## August 26

1. **Tree and NavTree.** Two tree components ship, and the docs sidebar uses NavTree.

## August 23

1. **Composer.** The input half of a conversation ships.

## August 20

1. **Docs in Shell, with search.** The docs site runs on its own Shell, renders every page with Kookie components, and has search.
2. **API tables from the types.** Prop tables are generated from the component types.

## August 19

1. **ScrollArea, SegmentedControl and Tabs.** Three more components ship.
2. **Builder.** A composition editor at /builder lets you lay out blocks, edit them and export real components.

## August 16

1. **Shell.** The app frame ships: panes that float or sit flush, a rail, a sidebar, and pane edges you can drag.
2. **Glass material.** Surfaces are built from one glass material with squircle corners, refraction and lit edges.

## August 10

1. **Hugeicons.** The docs use Hugeicons.

## July 31

1. **Kookie UI begins.** The repo starts on July 31, with color previews for any brand hue in light and dark.
